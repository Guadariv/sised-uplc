Política de privacidad de SISED-UPLC

Última actualización: 10 de octubre de 2026.

El Sistema Institucional de Seguimiento y Evaluación Docente (SISED-UPLC) facilita la participación de estudiantes en procesos de evaluación docente y el seguimiento académico.

1. Datos tratados

El sistema puede tratar el correo electrónico, nombre e identificador de cuenta obtenidos al iniciar sesión con Google; carrera, grupo y, cuando se solicite, matrícula; respuestas, puntuaciones y comentarios de evaluaciones docentes; y datos técnicos necesarios para operar y proteger el servicio.

2. Finalidades

Estos datos se utilizan para autenticar a los participantes, gestionar las jornadas de evaluación, prevenir participaciones duplicadas, registrar respuestas y generar reportes para el seguimiento y la mejora académica.

3. Inicio de sesión con Google

Google autentica la cuenta del estudiante y facilita los datos básicos autorizados para iniciar sesión. SISED-UPLC no solicita ni almacena la contraseña de Google.

4. Acceso a la información

Las evaluaciones están destinadas a personal autorizado para fines académicos. Los estudiantes no deben tener acceso a las respuestas individuales de otros participantes. Las participaciones pueden estar asociadas técnicamente a una cuenta, por lo que no se garantiza anonimato absoluto.

5. Servicios tecnológicos

La aplicación utiliza Google para autenticación, Supabase para autenticación y almacenamiento de datos y Vercel para alojamiento. Estos proveedores pueden procesar información técnica de acuerdo con sus políticas aplicables.

6. Conservación y protección

Los datos se conservarán durante el tiempo necesario para las finalidades académicas y administrativas aplicables, según los criterios que establezca la instancia responsable. Se aplicarán controles de acceso y medidas técnicas razonables para protegerlos.

7. Consultas y solicitudes

Para consultas, solicitudes de corrección o asuntos relacionados con los datos personales, escribe a guadariv@live.com.mx. Las solicitudes se atenderán conforme a los procedimientos aplicables.

8. Actualizaciones

Esta política podrá actualizarse si cambian las funciones del sistema, sus proveedores o los requisitos aplicables. La versión vigente estará disponible en esta página.

Importante: Antes del uso institucional general, este texto debe revisarse con la instancia responsable de protección de datos y alinearse con el aviso de privacidad institucional correspondiente.
